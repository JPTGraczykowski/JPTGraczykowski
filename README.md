## I make games

Both are written in Rust. Every texture, sprite, sound and piece of music is generated in code, so there are no hand-made asset files.

* [Ultima-J: The Abyss Below](https://github.com/JPTGraczykowski/ultima-j) - a remake of *Ultima Underworld: The Stygian Abyss* (1992), with a texture-mapped 3D dungeon, rune magic, conversations, an automap and a five-level quest. Builds for Linux, Windows and macOS are on the [Releases page](https://github.com/JPTGraczykowski/ultima-j/releases)
* [Stygian J-Ball](https://github.com/JPTGraczykowski/stygian-j-ball) - a DX-Ball brick-breaker set in an Ultima Underworld torch-lit dungeon. [Play it in your browser](https://jptgraczykowski.github.io/stygian-j-ball/), on a computer or a phone

## I build Rails apps

* [Mani Fiszki](https://github.com/JPTGraczykowski/mani-fiszki-rails) - an English learning platform with flashcards and fill-in-the-sentence exercises, built with Rails 8 and Hotwire. Live at [mani-fiszki.fly.dev](https://mani-fiszki.fly.dev/)
* [note-j](https://github.com/JPTGraczykowski/note-j) - a note-taking app with nested folders, tags, todos and Markdown notes with images, developed with AI agents working from PRDs and task lists
* [MCP Blog Poster](https://github.com/JPTGraczykowski/mcp_blog_poster) - a Model Context Protocol server for managing blog posts, built with the `fast-mcp` gem
* [AI Chat](https://github.com/JPTGraczykowski/ai_chat) - an AI chat application in Rails
